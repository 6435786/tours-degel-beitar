# שלטים – דגל

מערכת מעקב לתליית שלטים: הזנת כתובות, המלצות מטה, תכנון ומדידה בשטח, אישור יוסי, דפוס, מנוף ותלייה.

- כתובת: `https://6435786.github.io/tours-degel-beitar/signs/`
- מצב דמו (נתונים מדומים, בלי התחברות): `.../signs/?demo=1`

## איך זה בנוי
- `index.html` – כל האפליקציה (מסכים, כניסה עם גוגל, סנכרון חי דרך Firestore).
- `logic.js` – לוגיקה טהורה: תמחור, ייעוץ לחיסכון, שרשרת סטטוסים, פירוק כתובות.
- `logic.test.js` – בדיקות: `node --test signs/logic.test.js`.
- נתונים: פרויקט Firebase **נפרד** `signs-degel` (אוספים `signs` ו-`signsMeta`) — בלי שום שיתוף משתמשים או הרשאות עם אפליקציית הטיולים.
- תמונות: Cloudinary (preset `trips_upload`, תיקייה `signs`).

## הרשאות Firestore
הכללים מודבקים בפרויקט `signs-degel` (Firestore ← Rules) ומחליפים את כל התוכן שם.
אם בכניסה מופיעה הודעה ש-Firebase חוסם את הגישה, המסך עצמו מציג את הכללים המלאים להדבקה.
